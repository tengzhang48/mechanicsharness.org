How the review was done

I reviewed the diffusion page directly. Each of the other five pages had one parallel Claude review session using the same method, and I then re-checked each session's main findings against the files. Every review asked three questions: is the stated physics and mathematics right; does every quantitative or record claim match the file it cites; and do the failure explanations separate mathematical errors, unsupported conclusions, and execution or delivery problems.

Reference values were recomputed from the governing equations in new scripts that import no agent or project code (list below). Agents' code was read where a failure mechanism had to be identified, never run.

Each finding carries one label:

  • Checked I checked it against the files or recomputed it myself.
  • Reviewer A review session checked it against the files or recomputed it; I did not repeat that check.
  • Inferred A judgment or derivation, with its condition stated.

Reviewer That is after GPT (14:59) and Kimi P02 (14:46) finished, but before Kimi P05 (18:10), Azure (18:12) and Direct (18:47).   2. Checked GPT's success needs the same-family caveat. runs/P03_gpt61_sol/EVALUATION_STATUS.json: "automatic_scoring: withheld: solver and key organizer share the OpenAI family". PROCESS_LOG.md records that non-OpenAI solvers were chosen because Codex prepared the reference. The page does not mention this. Grok's check against the paper's equations mitigates it; say so in one sentence. Inferred Recall of the paper was not excluded either; Grok judged closed-book compliance only from logs.
  3. Reviewer "251 numerical checks" overstates. 196 are numerical comparisons; the other 55 check presence, uniqueness, row counts and admissibility. Suggested: "251 scorer checks, 196 of them numerical comparisons."
  4. Inferred The residual heading overstates. "Other residuals were substantial" describes max-norm finite-difference residuals of the memory equation. At V = 0.001 the memory term is stiff (1/(λV) = 10⁴), and the residuals drop to 0.8–3% at V = 0.1 and 0.15–0.4% at V = 10 while 174 of 180 field components pass. The body text is careful; the heading should be too. Suggested heading: "…while two constitutive residuals were large and unexplained".
