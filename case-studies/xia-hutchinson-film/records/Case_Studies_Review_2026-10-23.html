How the review was done

I reviewed the diffusion page directly. Each of the other five pages had one parallel Claude review session using the same method, and I then re-checked each session's main findings against the files. Every review asked three questions: is the stated physics and mathematics right; does every quantitative or record claim match the file it cites; and do the failure explanations separate mathematical errors, unsupported conclusions, and execution or delivery problems.

Reference values were recomputed from the governing equations in new scripts that import no agent or project code (list below). Agents' code was read where a failure mechanism had to be identified, never run.

Each finding carries one label:

  • Checked I checked it against the files or recomputed it myself.
  • Reviewer A review session checked it against the files or recomputed it; I did not repeat that check.
  • Inferred A judgment or derivation, with its condition stated.

Corrections

  1. Checked The intro limits DeepSeek's missing closed forms to case B. "Its finite-element values came within 1.6%, without closed forms for case B". The default run had no closed form for either case, and its answer says an analytic Wiener–Hopf solution would be needed. The card and the §9 table already say "no closed form". Suggested: "without closed forms for either case".
  2. Checked The solvers were told a published source existed. frozen_inputs/PROBLEM.md, lines 3–4, given to every solver: "This is the proposed source-faithful reproduction task; source solutions … are excluded." Reviewer TASK.md line 3 invites "source recognition". The note's "the paper … was withheld" is true; add that the agents knew a source existed. This bears on the lesson that recall cannot be excluded.
  3. Reviewer The false-wake claim overrode given information. PROBLEM.md states that "the relaxed cracked wake is reached far behind". DeepSeek's ANSWER.md:30–43 states the claim and, in the same section, quotes the finite-element wake that contradicts it (face σ₂₂ = 0.0029, σ₁₁ ≈ 0.735). That is an unsupported generalisation against both the premise and the run's own evidence, not only a face-condition slip. Suggested: "The claim contradicted both the problem statement and the finite-element wake its own answer reported."
  4. Reviewer Cite the stronger wake evidence. σ₁₁ ≈ 0.74σ₀ is 5% above the relaxed face value (1−ν)σ₀ = 0.70. σ₂₂ is cleaner: 0.003 at the faces and 0.114 at the centre, against exact values of 0 and 0.113 for W = ℓ.
  5. Reviewer Name the §7 error. ANSWER.md:113–115 says γ decreases with ℓ/H and concludes that σc increases with spacing. γ decreasing with ℓ/H means γ increases with H, so σc falls as H grows: a logic inversion in the last step, separate from the finite-element work.
  6. Checked Kimi's 2D check. §6 says "about 0.13% in both cases"; the page's own table gives at most 0.02% for case A and 0.13% for case B.
  7. Reviewer §8, D01 inputs. "The same two files" omits RUN_PROTOCOL.md, a one-page reporting schedule.
  8. Reviewer §3, experiments. The paper calls the comparison "similar, but not identical to Eq. (30)"; add "not identical".
