How the review was done

I reviewed the diffusion page directly. Each of the other five pages had one parallel Claude review session using the same method, and I then re-checked each session's main findings against the files. Every review asked three questions: is the stated physics and mathematics right; does every quantitative or record claim match the file it cites; and do the failure explanations separate mathematical errors, unsupported conclusions, and execution or delivery problems.

Reference values were recomputed from the governing equations in new scripts that import no agent or project code (list below). Agents' code was read where a failure mechanism had to be identified, never run.

Each finding carries one label:

  • Checked I checked it against the files or recomputed it myself.
  • Reviewer A review session checked it against the files or recomputed it; I did not repeat that check.
  • Inferred A judgment or derivation, with its condition stated.

Corrections

  1. Checked The literature claim outruns the record. Where: §4 row "New discovery" ("Later literature contains the corresponding exact short-time structure") and §3 "The later literature check". The GPT Challenge record says Atkinson–Craster and Yu 2018 "are not on disk", and whether the coefficient is given "as one value is not checked". Reviewer Yu 2020 gives α ≈ 0.735 only for νu = 0.5. Hui et al. 2013 give α = 1. The volume tip term was never checked against the literature. Atkinson–Craster 1991 appeared the same year as Detournay–Cheng 1991, so it is not "later". Suggested: "Yu et al. 2020, citing Atkinson and Craster 1991 (not read), give the same form with α ≈ 0.735 at νu = 0.5; the factorization reproduces it within 0.2%. Hui et al. 2013 give α = 1. The volume term has not been checked against the literature."
  2. Checked §3 contradicts itself. "The second was absent from all nine answers" is followed by "five of the nine non-GPT runs mentioned a zone of size √(ct)". Suggested: "None used r/√(ct) to define K or discussed the order of limits; five named a √(ct) tip zone but judged it only by its volume share."
  3. Checked The reasoning-off DeepSeek runs are a configuration error. The page labels them "reasoning off" but never says the setting was a mistake; the word "configuration" does not occur on it. Reviewer The multiphysics summary calls them "configuration error; superseded". The index pools them as "0/6 across the two settings". Report 0/3 with reasoning on, and list the reasoning-off runs under execution.
  4. Reviewer The confirmations were less independent than "separate routes" suggests. Both reviewers received GPT's answers and code (review_B_K10/codex/TASK.md:8). Grok's factorization was rewritten from scratch with the same kernel. Only the FE run is independent of the kernel, and it reads about 1% low. Inferred Codex and GPT also come from the same vendor.
  5. Reviewer The FE volume range is extrapolated. "About 2.2–2.4 when the face layer was included" rests on local slopes of 1.75–2.21 and decade fits of 1.88–2.11 that were still rising as t → 0; FE_CHECK.md says "Extrapolated … not enough to confirm the digits". Add "extrapolated".
  6. Reviewer "Physical-limit errors" for K = 1 is too strong. KEY.md grades the undrained value "partly": it is right under the reverse order of limits that the original wording allowed. Suggested: "gave the outer undrained value (graded partly); none identified the drained tip."
  7. Reviewer MP-06 is described two ways. The results table says its 0.82 "arose partly from grid smoothing"; §3, after correction P382, says it appeared before any diffusion step and came from smoothing. Make the table match §3.
  8. Reviewer The loading-2 "checked result" was not computed independently. The multiphysics summary marks the rejection of the free-swelling argument as the coordinator's own. Suggested: "D&C Eq. 39, consistent with the confined-region stress −ηp."
