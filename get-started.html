Get started and contribute

The battery benchmark is released (6 Nov 2026); the rock benchmark is in preparation (see the benchmark cards).

The code repository

github.com/tengzhang48/agent-mechanics-benchmarks-public holds the released benchmarks: for each, the task as the agents received it, the host that runs a submitted element, the scorer, the reference solution's code, the agents' submissions and the results, with a practice problem that runs from a clean checkout. It is the authoritative home for code and evaluation instructions; this site introduces the project.

What you will need

The hosts are written in Python and compile the agent's Fortran element with gfortran through NumPy's f2py, on the public abaqus_ufl solver. Abaqus itself is not needed to run them. The battery benchmark's README gives the install line and the two commands that score a saved element on its practice problem.

Report a problem or propose a case

You can already ask for your own element to be scored on the battery benchmark's hidden problem: score it on the practice problem first, then open an issue in the code repository (details in its CONTRIBUTING.md). We report the result of each check, not the hidden problem's setup. We plan to accept proposed cases once the evaluation workflow has been exercised on a contributed submission. For the benchmarks and their results, please open an issue in the code repository; for this website, open an issue in its repository.
