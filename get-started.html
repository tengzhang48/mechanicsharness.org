Get started and contribute

No benchmark code is released yet. Both benchmarks are in preparation (see the benchmark cards).

The first code release

The first code release will contain the released tasks, the host programs and scorers, reference data, citation information, and one example that runs from a clean checkout. It will be versioned in a public GitHub repository, which will remain the authoritative home for code and evaluation instructions; this site introduces the project.

What you will need

The hosts are written in Python with NumPy, and they compile the agent's Fortran element with gfortran through NumPy's f2py. Abaqus itself is not needed to run them.

Report a problem or propose a case

We plan to accept proposed cases and outside submissions once the evaluation workflow has been exercised on a contributed submission. Until the code repository opens, please open an issue in this site's repository, github.com/tengzhang48/mechanicsharness.org.

Citation
